🌊 WEC Multiresolution Control SimulatorThis repository contains a high-fidelity, time-domain simulator for a heaving point absorber Wave Energy Converter (WEC). Developed as part of a professional engineering portfolio, this project implements a Multiresolution Analysis (MRA) control strategy designed to maximize power capture in irregular sea states while strictly adhering to physical machinery constraints.🚀 Performance Showcase: MRA vs. BaselineThe simulator compares the proposed MRA controller against a standard LQR Baseline in a realistic sea state ($H_s = 2.5m, T_p = 8s$).MetricBaseline (LQR)MRA (Proposed)ImprovementMean Power14.04 kW17.16 kW+22.2%Capture Width Ratio (CWR)35.8%43.2%+7.4%Result: The MRA controller achieves superior energy extraction by focusing on high-density wave frequency bands.Safety: Heave displacement is maintained within $\pm 5m$ limits, and PTO force saturation is implemented to prevent mechanical failure.🧠 Engineering ArchitectureThe system is modeled using the Cummins Equation, representing complex fluid-structure interaction:$$(M + A_{\infty})\ddot{z}(t) + \int_{0}^{t} K(t-\tau)\dot{z}(\tau)d\tau + K_{res}z(t) = F_{exc}(t) + u(t)$$Technical Implementation:Radiation Approximation: The convolution integral is replaced by a 4th-order state-space model for real-time control feasibility.Numerical Methods: Built using Python 3.13, leveraging NumPy and SciPy for state-space stability analysis (Schur decomposition).System ID: Scripts included to process hydrodynamic coefficients from BEM (Boundary Element Method) data.
